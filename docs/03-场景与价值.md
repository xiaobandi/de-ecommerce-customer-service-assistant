# 03 · 场景与价值

## 谁在用

日均咨询 30-300 条、跨 2 个以上平台的一人店

## 三个典型场景

### 场景 A：售前智能导购
- **触发**：事件（买家消息）
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：意图识别→知识库检索→话术→商品推荐
- **收益**：高峰分流，月省 25h≈¥750

### 场景 B：订单/物流自动查询
- **触发**：事件
- **之后**：单号识别→物流接口→状态解读回复
- **收益**：查询类占咨询 40%+

### 场景 C：售后工单分流与安抚
- **触发**：事件
- **之后**：情绪识别→分级→安抚话术/转人工
- **收益**：拦截情绪波动致差评

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 月省客服工时约 60h≈¥1800 vs 月费 ≤¥60 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |

## 与人工的边界

本员工**不替代决策**。它负责把重复劳动做成清单与初稿，
把决策点（要不要发、要不要改价、要不要道歉）留给人。
